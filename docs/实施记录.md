## 本轮修复与证据

- 图片服务已改为用户授权的专用 Sevnx 配置，六张视觉稿与六张独立素材已生成；此前403不是当前阻塞。
- 批量创建按SKU排序加锁，减少逐单SQL；统一支付、取消、核销锁顺序。
- 库存预扣和归还各以一条HSET提交关键证据，不假设Lua运行时异常会回滚。
- 增加终态临时日志归档，保留数据库gate、有效资格和永久归还去重。
- 批量到期关闭与批量归还，避免高峰订单15分钟后逐单排队；已支付订单不会退库存。
- 恢复扫描跨轮保留cursor，避免大Hash下反复从0开始遗漏后部待修复项。
- 修复运营对账将未预扣拒绝当作处理中，库存及订单计数改为单SQL快照。
- 修复Vue写游记按钮误接收点击事件、false的ARIA状态、迟到订单响应覆盖新选择；增加10秒HTTP超时、原请求恢复及点赞权威校正。
- 价格先检查long范围再转换，允许0元；停用票种不可重新发布销售。
- 下单、原请求重试和支付回包校验用户、路由及当前申请/订单；日期切换后迟到回包不能覆盖新状态。已做真实成功后延迟响应专项，并在5190重跑完整浏览器流程。
- 修复多日期刷新后默认回到首个日期：按用户和景点保存所选SKU；匿名先选日期再登录也保留选择。正式5190验证恢复同票种、同日期SKU、同订单且无新POST。
- 前端验证使用Playwright+Edge，Browser插件未提供；真实二维码由独立jsQR解码验证。

构建、测试与原始压测结果以[验收与性能记录](验收与性能记录.md)为准。没有把连接数、429或无效重复点赞计入有效吞吐。
