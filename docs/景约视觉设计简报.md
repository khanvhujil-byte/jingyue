# 景约视觉设计简报

用户要求：品牌「景约」，蓝色、清新、真实风景与旅行感；全中文；详情页在服务器确认订单已落库后自动显示下单完成，无需再点处理结果。完整票务 V1.0 包括日期票、模拟支付、本人订单、电子票、授权核销和运营页面。

技术约束：沿用 Vue；导航、表单、日历、价格、状态、二维码和操作都以代码实现。设计稿是视觉参照，不能直接贴成可交互页面。风景为虚构演示景点，不能暗示真实景区官方售票。无虚构评分、销量和高并发数据。

## 统一视觉方向

- 白色主背景 #FFFFFF，浅蓝区块 #F2F8FD，主蓝 #1677D2，深色文字 #17324D，次要文字 #6B8095，边框 #DFEAF3。
- 清晰中文无衬线字，标题有足够层级，常规界面字 14–16px；适度圆角，不使用满屏药丸按钮和卡片套卡片。
- 蓝天、清水、远山、古镇、自然光摄影风格；风景本身保留自然色彩，不统一覆盖蓝色蒙层。
- 品牌为小型山水线条标记 +「景约」，不使用「山海之间」。导航为「景点门票」「游记」「我的订单」。
- 宽屏内容宽度约 1248px；移动端 390px，提供固定底部主操作且不遮挡内容。支持 360px。

## 设计稿清单

1. 首页完整页面：导航、风景主视觉与搜索、精选景点、游记预览、简洁页脚。
2. 景点详情和已建单状态：图片、简介、须知、票种日期日历，右侧原位出现「下单完成，待支付」及支付操作。
3. 我的订单与订单详情：状态筛选、待支付/待使用/已关闭列表、支付截止、关闭名额释放状态。
4. 运营工作台：景点、票种、SKU 生命周期、预热/发布/暂停、异常及对账；全部中文，无虚构运行指标。
5. 核销工作台：凭证输入、景点授权、核销结果与首次核销时间。
6. 手机电子票详情：景点/票种/日期/时间/有效状态/二维码，注明模拟票券。

## 状态与文案约束

正在提交 → 排队处理中 → 下单完成，待支付 → 模拟支付成功，已出票。未知结果保留原请求查询。只有 PAID 才显示电子票；CLOSED 显示是否仍在释放名额；USED 显示核销时间；EXPIRED 不显示可用入园操作。支付均写明「模拟支付，不扣真实资金」。

生成方式：六张初版页面视觉稿经用户明确授权，使用 imagegen 技能 CLI 连接用户平台生成。用户随后新增偏好，后续六张独立素材改用 sevnx-imagegen 技能。两种入口均使用用户指定平台、gpt-image-2.5 和专用 IMAGE_API_KEY；密钥仅从本机环境读取，不存入设计文件或仓库。
