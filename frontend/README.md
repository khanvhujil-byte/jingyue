# 景约前端

目的地浏览、活动票抢购、旅行手记与旅人账号的页面实现。后端架构、完整运行步骤和截图见[项目首页](../README.md)，源码学习见[项目教学](../docs/项目教学.md)。

## 启动

需要 Node.js 20+，没有第三方运行依赖。

```bash
npm run dev
```

打开 <http://127.0.0.1:5173>。默认使用内置虚构数据；合法格式手机号和验证码 `123456` 可体验登录。

真实服务默认转发到本机 `8081`，点击页面顶部“连接真实服务”切换。其他端口可通过 `API_TARGET` 设置；开发服务器将 `/api` 前缀移除后转发。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `src/app.js` | 页面、hash 路由与交互 |
| `src/api.js` | 真实接口、错误分类与长整数解析 |
| `src/orders.js` | 操作追踪、防重复提交与状态查询 |
| `src/demo.js` | 独立体验数据与模拟状态 |
| `src/storage.js` | 按模式和账号隔离会话存储 |
| `src/view.js` | 视图、转义和票种状态 |
| `assets/` | 本地 SVG 插画与图标 |

## 验证和构建

```bash
npm test
npm run build
```

输出 `dist/`，可部署到静态托管服务。项目内的浏览器脚本可使用另行安装的 Playwright 运行。接口字段说明见[接口映射](docs/接口与业务映射.md)。
